## Reporting a Vulnerability

We take the security and privacy of our software seriously. If you discover a security vulnerability, please disclose it responsibly.

### How to Report
1. **GitHub Private Vulnerability Reporting (Preferred)**:
   - Navigate to the [Security > Advisories tab](https://github.com/18basils/Hotelier-Staycation/security/advisories/new) on GitHub and click **"Report a vulnerability"**.
   - This opens a private, encrypted thread directly with the maintainers without exposing exploit code publicly.
2. **Direct Contact**:
   - If private vulnerability reporting is unavailable, contact the project maintainer via their GitHub profile [@18basils](https://github.com/18basils).

### What to Include
* Description of the vulnerability and its potential impact.
* Minimal Proof of Concept (PoC) or reproduction steps.
* Affected components or endpoints (e.g., API route, authentication flow, or client view).

### Response Timeline
* **Initial Acknowledgement**: Within 48 hours.
* **Triage & Assessment**: Within 5 business days.
* **Fix & Advisory Release**: Critical vulnerabilities receive immediate patch priority.
